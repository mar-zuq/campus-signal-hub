# 🚀 CampusSignal

**Your college has the information. We make sure you don't miss what matters.**


CampusSignal is an AI-powered triage and logistics layer designed specifically for engineering students balancing intense academics with extracurricular leadership. Developed for the **DotSlash '26 Rapid Prototyping Challenge**, it solves the critical problem of information overload—where vital KTU lab deadlines, timetable shifts, and fest announcements are scattered across chaotic WhatsApp groups, Instagram posters, and department PDFs.

## ⚠️ The Problem
Important campus information is unstructured. Students miss deadlines buried in group chats, and student organizers accidentally schedule overlapping events (causing attendance drops) because campus data lives in silos.

## 💡 The Solution
CampusSignal acts as an intelligent, automated logistics assistant. It parses unstructured noise, flags scheduling conflicts, and automates administrative campus tasks like generating official KTU Duty Leave letters.

## ✨ Key Features

*   **Universal AI Ingest:** Paste a messy WhatsApp message or upload a fest poster. The application processes the entity, urgency, date, time, and venue, transforming it into a clean, actionable task card.
*   **The Conflict Engine (Coordinator View):** Analyzes campus schedules to visually flag overlapping events. If a DotSlash competition clashes with a major event like Drishti '26, the app flashes an amber warning predicting an attendance drop, allowing organizers to pivot.
*   **KTU Utility Hub:** 
    *   **Auto-Duty Leave:** Generate a perfectly formatted Duty Leave letter addressed to the CSE HOD in one click, automatically populated with the student's register number, roll number, and event details.
    *   **Activity Points Tracker:** A visual widget to track progress toward the mandatory 100 KTU activity points requirement.
*   **Smart Triage & Planning:** 
    *   **Catch Me Up:** Instantly summarizes missed messages into prioritized actions.
    *   **2 Hours Free Plan:** Analyzes the schedule to suggest the most urgent deadline to tackle first.
*   **Command Palette:** Press `Cmd+K` to open a Spotlight-style search to instantly find any campus notice, venue, or event.

## 🎨 Design System
*   **Aesthetic:** Hyper-minimalist, productivity-focused dark mode inspired by Linear and Vercel. 
*   **Palette:** Obsidian background (`#0B0F17`), elevated dark gray cards (`#161B26`), and subtle borders (`#2E3648`).
*   **Accent Badges:** Crimson (Critical Actions), Cyan (Schedule Shifts), Emerald (Opportunities), and Amber (Conflict Alerts).

## 🛠️ Tech Stack

*   **Frontend Framework:** React 
*   **Styling:** Tailwind CSS
*   **Icons & Typography:** Lucide React, Inter/Geist fonts
*   **Deployment & Generation:** Lovable.dev
*   **State Management:** React Hooks (Real-time UI updates without a database dependency for rapid prototyping)
